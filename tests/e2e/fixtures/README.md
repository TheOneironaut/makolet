# End-to-end clean-room fixtures

These four small XML files were independently authored for Makolet and are
licensed under Apache-2.0 with the rest of this repository. They model one store,
one initial full price observation, one later price delta, and one promotion with
a deliberately broad business-valid window so the real-service test does not
expire as wall-clock time advances. They contain no retailer data, credentials,
signed URLs, or third-party source code.
