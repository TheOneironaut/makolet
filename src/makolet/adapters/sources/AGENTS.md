# Source-adapter rules

Keep discovery separate from downloading and parsing. Add configuration for retailers
that share observed portal behavior; add code only for a real protocol or listing
variation. Stable remote identity must not depend on expiring signed URLs. Allow only
configured public hosts and schemes, bound pagination, scrub credentials, and preserve
clean-room evidence in `docs/research/source-research.md`.

Every family needs legal minimal fixtures, contract tests, a low-volume opt-in live
test, and a `docs/source-coverage.md` update. Never copy code or fixtures from a
restricted or unlicensed reference repository.
