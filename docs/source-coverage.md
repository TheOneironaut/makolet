# Source coverage

Research matrix verified: 2026-08-11. Bounded credential-free HTTPS listing smokes
for `shufersal`, `king-store`, `maayan-2000`, `global-retail`, `hyper-cohen`,
`hazi-hinam`, and `city-market` were reverified sequentially on 2026-08-18 after the
Matrix empty-wrapper fix at source digest
`0daaa40f0db95f674e61340e66ce30bfdffab5062670b2ed2e40690ab8870805`.
`hyper-cohen` had failed closed earlier that morning on a publisher-empty Matrix
`[]` catalog; the later window returned a nonempty catalog and is the current
listing evidence. This matrix is intentionally honest: `researching` is not
implemented support, and fixture coverage is not a live smoke-test result.

The scope is the Competition Authority's [2025 large-retailer list corrected on
23 July 2026](https://www.gov.il/he/departments/legalInfo/bigretailerslist2025up).
The page's stated section-14 exclusion is tracked as a scope limitation in the
research notes. The 28-row registry and every accessible portal-family discovery
adapter are implemented and covered by clean-room fixtures; selected credential-free
families also have bounded live smokes. A verified endpoint or historical mapping is
still not, by itself, evidence that a feed is currently healthy in production.
Certificate-verified HTTPS/FTPS is enabled normally. Legacy NCR plain FTP is
fail-closed unless `MAKOLET_ALLOW_INSECURE_FTP=true`; even when explicitly enabled,
its archived provenance is unauthenticated and cannot rule out network substitution.

A separate opt-in representative-ingestion harness fixes Maayan 2000 to the BINA
Price-delta/store-001 partition and exactly one credential-free HTTPS file. It
exercises production download, immutable S3 archival, XML parsing, PostgreSQL apply,
isolated-catalog matching, publisher-free replay, and CLI/API/MCP provenance parity
inside unique disposable service scopes. On 2026-08-18 it passed on source digest
`0daaa40f0db95f674e61340e66ce30bfdffab5062670b2ed2e40690ab8870805`
against the current publisher, PostgreSQL 18.4, and SeaweedFS 4.40: exactly one newly
completed bounded Price object produced accepted rows, unchanged replay produced zero
history events without publisher access, every public interface returned identical
provenance, and a post-run database listing found zero `makolet_live%` names. All
seven documented credential-free HTTPS listing lanes passed in the same later
window, including a nonempty `hyper-cohen` catalog. This is source-coverage
evidence, not performance or whole-release acceptance.
